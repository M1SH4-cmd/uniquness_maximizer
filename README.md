# Uniqueness Maximizer

**Uniqueness Maximizer** — настольное приложение для повышения оригинальности текстов и снижения заметности следов использования ИИ.  
Проект ориентирован на обработку документов Microsoft Word и предназначен для предварительной аналитической и текстовой модификации контента.

Приложение работает с файлами форматов **.doc** и **.docx**, анализирует содержимое и применяет алгоритмы переработки текста для повышения показателей уникальности.

---

## Возможности

- Загрузка и обработка Word-документов (.doc, .docx)
- Повышение оригинальности текста
- Снижение признаков использования ИИ в тексте
- Работа с большими текстами
- Многопоточная обработка данных
- Графический интерфейс на Qt

## Сборка проекта

Проект собирается с использованием **CMake**.

### Требования

- CMake ≥ 3.16
- Qt 6.10.1
- MSVC (Visual Studio 2022 рекомендуется)
- Windows 10 / 11

---

### Сборка (Windows / cmd)

```cmd
mkdir build
cd build
cmake -G "Visual Studio 17 2022" -A x64 ..
cmake --build . --config Release
````

---

### Сборка (bash)

```bash
mkdir build
cd build
cmake ..
cmake --build . --config Release
```
